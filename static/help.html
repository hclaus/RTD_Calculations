Overview

This tool validates UV disinfection performance for a laminar-flow cylindrical reactor, following the methodology and reactor design ("BLUCIFRR") described in UV-C Dose-Response Behavior of Airborne (Aerosolized) Challenge Agents I: Theoretical Foundation (Blatchley, Jongewaard, Claus, Hernandez, Shorno & Bowers). A "Microbiological / Chemical" toggle on the calculator page switches between two applications of the same underlying reactor model -- see Chemical actinometry below for the chemical mode. In microbiological mode, it supports two workflows:

  • Forward prediction — given a reactor's geometry, flow rate, and a target organism's inactivation rate constant (k) and the average UV fluence rate (Eavg), predict the overall survival ratio C/C0 the reactor will deliver.
  • Back-solving from a bioassay — given a measured C/C0 from a real bioassay run, back-solve for the rate constant k that is consistent with that measurement under the reactor's actual (non-ideal) flow pattern. This is the core of UV reactor validation: a single bioassay already reflects the true dose non-uniformity, so back-solving through the correct flow model gives a validated k rather than one biased by assuming everyone gets the same dose.

Reactor hydraulics & laminar flow

For steady, fully-developed laminar flow in a circular tube, the velocity profile is parabolic: U(r) = U0·(1 − r²/a²), where U0 is the centerline (maximum) velocity and a is the tube radius. The cross-section-averaged (mean) velocity is exactly half the centerline velocity: Uavg = U0/2, so U0 = 2·Uavg. Given the volumetric flow rate Q, Uavg = Q /(60·π·a²) (the 60 converts cm³/min to cm³/s).

Is the flow actually laminar? The Reynolds number Re = ρ·Uavg·(2a)/µ compares inertial to viscous forces. This tool reports a plain-language verdict using standard pipe-flow thresholds: Re < 2300 → Laminar, 2300 ≤ Re ≤ 4000 → Transitional (uncertain), Re > 4000 → Turbulent. The whole RTD model below assumes laminar flow, so a Transitional/Turbulent verdict means the model's assumptions may not hold for that scenario.

Residence Time Distribution (RTD) theory

Because the velocity profile is parabolic, fluid near the tube's centerline moves roughly twice as fast as the cross-sectional average, while fluid near the wall moves much slower. A single "residence time" doesn't exist — instead, different fluid elements experience a distribution of residence times. For a non-diffusing tracer in laminar flow, Taylor (1953) derived the exact closed-form residence time distribution density function: 

E(t) = L / (U0·t²)   for t > L/U0
E(t) = 0              for t ≤ L/U0

where L/U0 is the minimum possible residence time (experienced by fluid exactly at the centerline). This tool integrates E(t) from L/U0 out to 100·L/U0 — a practical stand-in for infinity, since E(t) decays rapidly and the contribution beyond that point is negligible.

Why is it valid to ignore diffusion? Taylor's derivation assumes the tracer doesn't diffuse radially between streamlines. Whether that's reasonable depends on the Peclet number, Pe = Uavg·L/D, which compares advective transport to diffusive transport (D is the challenge agent's diffusivity in air). Per Bowers & Miller (2025), for Pe ≳ 10⁵ advection dominates and diffusion can be neglected. This matters a great deal for aerosolized challenge agents: a ≥1 µm bioaerosol diffuses roughly 5 orders of magnitude slower than a typical gas-phase actinometer molecule, so the zero-diffusion assumption is comfortably satisfied for bioaerosols (typical reactor Peclet numbers run well above 10⁸) but needs more care for gas-phase chemistry. This tool reports a plain-language verdict: Pe ≥ 1e5 → Advection-dominated (diffusion negligible) — RTD model assumptions hold; otherwise a caution that diffusion may be significant.

Chick-Watson first-order inactivation kinetics

Within any single fluid element (treated as its own small batch reactor), microbial inactivation is modeled with first-order (Chick-Watson) kinetics: the surviving fraction decays exponentially with the UV dose received, 

(C/C0)_batch(t) = exp(-k·Eavg·t)

where k is the organism-specific inactivation rate constant (cm²/mJ) and Eavg·t is the dose (fluence, mJ/cm²) accumulated over residence time t at average fluence rate Eavg (mW/cm²).

Why RTD-based dosing differs from a naive average dose

Combining the per-element kinetics above with the RTD density function via the Segregated Flow Model gives the reactor's true overall survival ratio as a weighted average over every possible residence time: 

(C/C0)_reactor = ∫₀^∞ (C/C0)_batch(t) · E(t) · dt

This is exactly what the "C/C0 (reactor)" headline result and the simulated C/C0 table compute. Compare this to the naive assumption that every fluid element receives the same, average dose: Davg = Eavg·q (using the mean residence time q = L/Uavg), giving a "well-mixed" survival estimate C/C0_well-mixed = exp(-k·Davg).

The sweep chart plots both curves against Davg on a log-scale y-axis. The well-mixed curve is always optimistic (predicts more disinfection than actually occurs) because it ignores the slow-moving fluid near the tube wall that receives far less dose than average — and that under-dosed fluid dominates the population of survivors. This gap is the entire reason RTD-based dose accounting matters for reactor validation, and it widens rapidly at higher doses (see the "% relative difference" column).

The solver: back-solving k or Eavg from a measurement

Given a measured bioassay survival ratio R = C/C0, the tool numerically solves (C/C0)_reactor(k) = R for k (holding Eavg fixed), or (C/C0)_reactor(Eavg) = R for Eavg (holding k fixed). Internally this uses a bracketed root-finder (Brent's method) over a search range — the "solver bracket" — that must contain the true answer: the tool needs one bracket endpoint where the predicted C/C0 is above R and one where it's below.

The default brackets (k: 0.001–50 cm²/mJ; Eavg: 0.0001–3 mW/cm²) match the original spreadsheet tool's defaults. If your measured C/C0 falls outside what's reachable within the current bracket, you'll see a clear error rather than a silently wrong answer — widen the relevant bracket in the Advanced settings panel and recalculate.

Chemical actinometry

Switching the calculator's mode to "Chemical" reuses this exact same reactor-geometry and RTD-integration engine, with a photochemically-derived rate constant kp in place of the microbial rate constant k. This models a chemical actinometer (e.g. CBr4 photolysis) run through the same non-ideal laminar-flow reactor, per the homogeneous gas-phase photolysis kinetics derived in slide 15 of the Theoretical Foundation deck: 

kp = σ · Φ · J
J  = 1 / (1000 · Up)
Up = h · c / λ

where σ is the actinometer compound's molar absorption cross-section (cm²/molec) at the chosen wavelength, Φ is its quantum yield (molecules converted per photon absorbed), Up is the energy of a single photon at wavelength λ (computed from Planck's constant h and the speed of light c), and J converts a fluence rate (mW/cm²) into an actinic photon flux. Once kp is known, it plugs directly into the same (C/C0)_batch(t) = exp(-kp·E'·t) kinetics and RTD integration used for microbiological predictions above — the reactor doesn't know or care whether the "rate constant" represents a microbe or a molecule.

Why back-solve E' instead of kp? In chemical actinometry, σ and Φ are known literature properties of the compound, so kp is a known, fixed quantity rather than something to validate. What's actually uncertain is the reactor's true fluence rate — so the roles are flipped relative to the microbiological workflow: the "Calculate E' from measured C/C0" table holds kp fixed and back-solves the fluence rate E' each actinometer sample must have experienced to produce its measured conversion, using the same bisection solver described above.

A note on σ: three different literature values for CBr4's absorption cross-section were found while researching this tool (1.28×10⁻¹⁷, 2.85×10⁻¹⁸, and 1.32×10⁻¹⁷ cm²/molec, from different sources). The default here matches the original spreadsheet's own value — treat it as a starting point to replace with the literature value appropriate to your compound and wavelength, not a settled constant.

Diffusivity from molecular weight. The Peclet number (see RTD theory above) needs a diffusivity, but chemical actinometer molecules diffuse roughly 5 orders of magnitude faster than the bioaerosols the microbiological mode's diffusivity default assumes — reusing that default here would be physically wrong. Instead, chemical mode estimates diffusivity in air from the compound's molecular weight alone, via a power-law fit D = a·MWb to four gas-phase compounds from slide 10 of the Theoretical Foundation deck (Benzaldehyde, 1,2,4-Trimethylbenzene, Styrene, and CBr4; MW 104–320 g/mol, D 0.068–0.073 cm²/s). A plain 1/√MW (Graham's-law-style) scaling was tried first and rejected — it overshoots by >60% at the light end of this range, because for a trace compound diffusing through air, the relevant reduced molar mass is dominated by air's own molecular weight (~29 g/mol) once the compound is much heavier than that, making diffusivity far less sensitive to the compound's own weight than 1/√MW implies. The fitted power law matches all four reference compounds within 2%. This estimate updates the same shared "Diffusivity" input used by the Peclet number calculation above — editing molecular weight recomputes it automatically, and the field remains editable if you have a literature diffusivity value you'd rather use directly.
